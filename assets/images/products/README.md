# Product Images

Place your product images here following these specifications:

## Image Requirements

- **Format**: WebP (preferred) or JPG
- **Dimensions**: 400x400px (will display at 200x200px for retina)
- **Aspect Ratio**: 1:1 (square)
- **Max File Size**: 200KB
- **Background**: White or transparent
- **Naming**: product-1.jpg, product-2.jpg, etc.

## Required Images

- product-1.jpg - Sports Research Astaxanthin
- product-2.jpg - Pure Encapsulations Astaxanthin  
- product-3.jpg - NOW Foods Astaxanthin
- product-4.jpg through product-10.jpg (add as you complete the reviews)
- og-image.jpg (1200x630px for social sharing)
- favicon.ico (website icon)

## Optimization Tips

1. Compress images using tools like TinyPNG or Squoosh
2. Convert to WebP format for better performance
3. Keep file sizes under 200KB
4. Use descriptive filenames
5. Ensure product labels are clearly visible
